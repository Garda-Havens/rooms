# rooms

Sito di Garda Havens (www.gardahavens.com), pubblicato con GitHub Pages.

## Dove sta cosa

| Cartella / file | Contenuto |
|---|---|
| `*.html` (cartella principale) | Le pagine del sito, in italiano (`-it`) e inglese. Non spostarle: i loro indirizzi sono su Google, nelle email e negli script. |
| `favicon.png`, `logo.png` | Icone del sito (restano qui perché sono citate con l'indirizzo completo). |
| `static/css/style.css` | Stile di tutto il sito. |
| `static/js/prices.js` | **Listino prezzi** unico (pagina Camere e generatore). |
| `static/js/gh-calendar.js` | Calendario usato nella pagina Camere e nel modulo Prenota. |
| `static/js/seasonal-logo.js` | Logo di Natale / Halloween / Pasqua nella home, in base alla data. |
| `static/js/slideshow.js` | Finestra delle camere ed elenco delle loro foto. |
| `static/js/esterno-photos.js`, `reveal.js` | Foto del giardino nella home, animazioni allo scorrimento. |
| `static/img/camere/1` … `6` | Foto delle camere. |
| `static/img/esterno/` | Foto del giardino / esterno. |
| `static/img/loghi/` | Logo normale e loghi di stagione. |
| `static/img/` | Altre immagini (home, guida, bandiere, partner). |
| `generator/` | Generatore di offerte (privato, con codice di accesso). |
| `apps-script/` | Copie degli script Google (richieste dal sito e calendario camere). Il codice vero sta su script.google.com. |
| `tools/sync-photos.py` | Dopo aver aggiunto o tolto foto delle camere: `python3 tools/sync-photos.py`. |
